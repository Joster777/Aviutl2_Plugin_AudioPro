# AudioPro - AviUtl ExEdit2 汎用プラグイン

音声の加工をまとめて行える、**音声フィルタ効果のセット** です。
ノイズ除去、イコライザー、コンプレッサー、ラウドネス調整、ダッキング、ピッチシフトの6つを追加します。

実況・解説・ナレーション動画で、声を聞きやすく整えるのに便利です。

※作者は音響関係に詳しくないため、正しく動作しているかはわかりません。

## フィルタ効果一覧

オブジェクトの「フィルタ効果の追加」から、次の6つを選べます(「音声効果」の項目に追加されます)。

| フィルタ効果 | できること |
|---|---|
| **ノイズ除去(AudioPro)** | エアコン・PCファン・ホワイトノイズなどの定常ノイズを低減。電源のハムノイズ(50Hz / 60Hz)のカット |
| **イコライザー(AudioPro)** | ローカット・ハイカット + 5バンドの音質調整。プリセットも使える |
| **コンプレッサー(AudioPro)** | 音量の大小の差を縮めて、聞きやすくする |
| **ラウドネス調整(AudioPro)** | 目標の音量(LUFS)に自動で揃える |
| **ダッキング(AudioPro)** | 指定したレイヤーの声に合わせて、BGM の音量を自動で下げる |
| **ピッチシフト(AudioPro)** | 速度を変えずに、声の高さを半音単位で変える |

## 動作環境

- AviUtl ExEdit2(バージョン○○以上)
- Windows 10 / 11

## 導入方法

1. [Releases](../../releases) ページから、最新版の zip をダウンロードします。
2. zip を解凍し、`AudioPro.aux2` を AviUtl ExEdit2 のプラグインフォルダにコピーします。
3. AviUtl ExEdit2 を起動(再起動)します。

## 使い方(共通)

1. 音声オブジェクト(または音声を含む動画オブジェクト)を選びます。
2. 「フィルタ効果の追加」から、使いたい「○○(AudioPro)」を選びます。
3. 設定画面で、各項目を調整します。

複数のフィルタ効果を組み合わせて使えます。声の編集なら、次の順に並べるのが基本です。

> ノイズ除去 → イコライザー → コンプレッサー → ラウドネス調整

## 各フィルタ効果の詳細

### ノイズ除去

定常ノイズ(エアコン、PCファンなど)を低減します。

| 項目 | 内容 | 範囲(初期値) |
|---|---|---|
| 低減量(dB) | ノイズを下げる量 | 0 〜 40 (12) |
| ノイズ判定の高さ(dB) | ノイズとみなす音量の基準 | 0 〜 20 (5) |
| 開く速さ(ms) | 声が入ったときの反応の速さ | 1 〜 100 (5) |
| 閉じる速さ(ms) | 声が止まったときの戻りの速さ | 10 〜 1000 (120) |
| ハムノイズ | 電源由来のノイズをカット(なし / 50Hz 東日本 / 60Hz 西日本) | なし |

低減量を上げすぎると、声が不自然になることがあります。少しずつ上げてください。

### イコライザー

ローカット・ハイカットと、5つの帯域(低域・中低域・中域・中高域・高域)で音質を調整します。

**プリセット**
- カスタム(下のバーを使う)
- 声をくっきり
- 声をまろやかに
- BGMの声帯域を空ける(BGM に掛けて、声の邪魔にならないようにする)
- 電話
- ラジオ
- 低音を強く
- こもり除去

プリセットを選んだときは、カスタム用のバーが隠れます。細かく調整したいときは「カスタム」を選んでください。

| 項目 | 範囲 |
|---|---|
| ローカット(Hz) / ハイカット(Hz) | 0 は「オフ」 |
| 各帯域の周波数(Hz) | 低域 20〜500 / 中低域 50〜1000 / 中域 200〜5000 / 中高域 1000〜10000 / 高域 2000〜20000 |
| 各帯域のゲイン(dB) | -18 〜 +18 |
| 中低域〜中高域の Q | 0.1 〜 10 |

### コンプレッサー

大きい音を抑えて、音量のばらつきをならします。

| 項目 | 内容 | 範囲(初期値) |
|---|---|---|
| しきい値(dB) | これを超えた音を抑える | -60 〜 0 (-18) |
| レシオ | 抑える強さ | 1 〜 20 (3) |
| アタック(ms) | 効き始めの速さ | 0.1 〜 200 (10) |
| リリース(ms) | 戻る速さ | 5 〜 2000 (120) |
| ニー(dB) | 効き始めのなめらかさ | 0 〜 24 (6) |
| メイクアップ(dB) | 抑えた分の音量を持ち上げる | 0 〜 24 (0) |
| オートメイクアップ | 持ち上げを自動で行う(オンにするとメイクアップは隠れます) | オフ |
| ミックス(%) | 元の音との混ぜ具合(パラレルコンプレッション) | 0 〜 100 (100) |

### ラウドネス調整

音量を、目標のラウドネス(LUFS)に揃えます。

**モード**
- **自動追従**: どの音声でも使えます。音量の変化に合わせて、リアルタイムに調整します。
- **ファイル全体を解析して一定ゲイン**: ファイル全体を解析して、全体に同じゲインを掛けます。

| 項目 | 内容 | 範囲(初期値) |
|---|---|---|
| 目標ラウドネス(LUFS) | 揃えたい音量 | -40 〜 -6 (-16) |
| 追従の速さ(dB/秒) | 自動追従のモードのみ | 0.5 〜 30 (6) |
| 測定の平均化時間(秒) | 自動追従のモードのみ | 0.5 〜 10 (3) |
| 最大ブースト(dB) | 持ち上げる量の上限 | 0 〜 40 (18) |
| 最大カット(dB) | 下げる量の上限 | 0 〜 40 (18) |
| リミッター | 音割れ(クリップ)を防ぐ | オン |
| 天井(dBFS) | リミッターの上限 | -12 〜 0 (-1) |

ファイルを解析できないときは、自動追従で処理します。

### ダッキング

BGM などに掛けて、**指定したレイヤーに声があるとき、自動で音量を下げます。**

| 項目 | 内容 | 範囲(初期値) |
|---|---|---|
| 対象レイヤー(開始・終了) | 声があるレイヤーの範囲 | 1 〜 100 (1) |
| 下げる量(dB) | 声があるときに下げる量 | 0 〜 48 (12) |
| 先読み(秒) | 声が始まる少し前から下げる | 0 〜 2 (0.15) |
| 下げる速さ(ms) | 下がるまでの速さ | 1 〜 1000 (80) |
| 保持(ms) | 声が止まっても、下げた状態を保つ時間 | 0 〜 3000 (300) |
| 戻る速さ(ms) | 元の音量に戻る速さ | 10 〜 5000 (600) |
| 声の大きさも見る | オンにすると、ファイルを解析して、小さい音を声とみなさない | オフ |
| 声とみなす音量(dBFS) | 上の項目がオンのときのみ | -80 〜 -10 (-40) |

**使い方**
1. BGM のオブジェクトに「ダッキング」を追加します。
2. 「対象レイヤー」に、声(ナレーション)があるレイヤー番号を指定します。

### ピッチシフト

速度を変えずに、声の高さを変えます。

| 項目 | 内容 | 範囲(初期値) |
|---|---|---|
| ピッチ(半音) | 高さの変化 | -24 〜 +24 (0) |
| 窓の長さ(ms) | 処理の細かさ | 20 〜 120 (50) |

窓の長さを変えると、音質と遅れ(レイテンシ)のバランスが変わります。

## 注意事項

- ノイズ除去やピッチシフトなどの処理は、声の種類や音質によって、**音が不自然になる** ことがあります。聞きながら調整してください。
- ピッチシフトは、処理の都合で、**わずかな遅れ**(窓の長さの約半分)が生じます。
- 実行前に、プロジェクトの保存(バックアップ)をおすすめします。
- 本プラグインを使用したことによる、いかなる損害についても責任を負いません。

再現手順や、使用している AviUtl ExEdit2 のバージョンも書いていただけると助かります。
